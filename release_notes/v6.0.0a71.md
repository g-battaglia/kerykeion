# v6.0.0a71 — Repository-wide correctness and documentation review

This alpha is a broad hardening release. It follows repeated independent code,
documentation, and release audits rather than a single feature addition.

## Runtime contract hardening

- Ephemeris sessions now reject unknown frames, non-finite USER ayanamsha
  parameters, unsafe nesting, and invalid topocentric coordinates before state
  can be corrupted or a default frame selected silently.
- Predictive factories consistently reject non-finite Julian Days, invalid
  ranges, counts, locations, orb settings, and malformed filters even when an
  explicit empty request would otherwise bypass backend work.
- Astro-cartography, fixed-star discovery, heliacal searches, primary
  directions, occultations, eclipses, aspects, and transit calculations gained
  focused boundary regressions for the bugs found during the review.
- Astro-cartography now rejects malformed/unknown planet filters and non-finite
  subject Julian Days, and caps projected grids at 1,000,000 line points;
  fixed-star discovery likewise validates its subject Julian Day before empty
  catalog/planet shortcuts.
- Aspect entry points reject non-string or non-finite per-point orb adjustments.
  Primary-direction specula now use the requested planetocentric equatorial
  frame, strip sidereal labeling from physical RA/declination calculations, and
  preserve Topocentric observer altitude on the subject model.
- The isolated package smoke test builds an sdist and wheel, installs the wheel
  without the source tree, imports it, and renders a chart with packaged assets.

## Documentation and quality gates

- The public-API coverage audit now checks all explicit package-root exports
  across the README, AI guide, maintained documentation, and examples.
- The executable Markdown gate covers every maintained runnable snippet.
- Factory signature tables, timing guides, backend licensing/range guidance,
  fixed-star configuration, SVG metadata, and release/development references
  were synchronized with the implementation.
- All gates run locally through `poe` (the project deliberately has no hosted
  CI): `quality` for lint/types/tests, `docs:check` and `docs:snippets` for the
  documentation gates, and `build:smoke` to verify the built wheel in
  isolation.
