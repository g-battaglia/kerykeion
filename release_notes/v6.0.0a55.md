# v6.0.0a55

This alpha reverts the short-lived `6.0.0b1` beta back to the alpha channel and
lands a broad stabilization pass: process-wide thread safety for ephemeris
access, sidereal-zodiac correctness across every search and refinement path,
aspect and SVG-rendering fixes, hardened event finders and packaging cleanup —
followed by a five-round review with a final hardening pass.

## Thread safety and sidereal correctness

A shared `ephemeris_session` context manager in `kerykeion.ephemeris_backend`
now serializes ephemeris access for all factories; `swe.close()` is never called
directly, and the pinned libephemeris calc mode survives session resets.
Sidereal calculations were corrected across planetary returns (the crossing
search now runs in the subject's zodiac frame), transit refinement, relocation
house cusps, fixed-star discovery, astrocartography and planetary nodes — none of
which now mix tropical longitudes into a sidereal chart.

## Public API surface

Every public Pydantic model (87) is now importable from `kerykeion.schemas`, the
canonical home the `kr_types` deprecation points to; feature subpackages and the
package root export the models their factories return. A new regression test,
`tests/core/test_public_api_surface.py`, locks the policy (schemas parity,
subpackage exports, factory-return exports, `get_type_hints` on every model,
`*Model` naming). Eight new-in-v6 classes were renamed to the `*Model`
convention (`SecondaryProgressionsResult` → `SecondaryProgressionsResultModel`,
`ACGLine` → `ACGLineModel`, `SpeculumEntry` → `SpeculumEntryModel`, …) with the
old names kept as deprecated aliases. `kerykeion.__version__` is now read from
package metadata at import time, and importing a removed v5 entry point
(`AstrologicalSubject`, `KerykeionChartSVG`, `NatalAspects`, `SynastryAspects`)
raises an `ImportError` naming the v6 replacement.

## Aspects, charts and events

The South Node's speed is no longer negated (fixing applying/separating
classification); geometric opposite pairs and star–star pairs no longer emit
fake aspects. SVG output XML-escapes user strings and sanitizes filenames,
exactly-conjunct planets keep both glyphs, and the classic theme defines its
base palette so inlined CSS variables no longer produce empty `fill` values.
`get_transit_events` splits recurring/retrograde passes into separate events and
warns on under-sampled fast bodies; exact-moment refinement now uses a true
ternary search. Event finders resolve DST-gap midnights, raise instead of
silently truncating on backend errors, and accept lowercase-`t` ISO strings.

## Tooling and packaging

A plain `pytest` run auto-detects the loaded ephemeris tier and skips
out-of-range tests with explicit reasons instead of failing; `poe build:smoke`
builds the sdist and wheel and renders a natal chart from the installed wheel in
isolation. `libephemeris` is now installed from PyPI (pin relaxed to
`>=2.0.2,<3.0.0`), the dead `MANIFEST.in` is removed, and the quality gates
(mypy, pyright, ruff) pass. The `NatalAspectsModel` / `SynastryAspectsModel`
aliases were removed (use `SingleChartAspectsModel` / `DualChartAspectsModel`).
