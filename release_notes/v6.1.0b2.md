# Kerykeion 6.1.0b2

Prerelease · Python 3.12+ · library and CLI released together.

Both distributions use `6.1.0b2`; the CLI pins `kerykeion==6.1.0b2` exactly.
The library pins the published `libephemeris==4.0.0b2` from PyPI.

## Scope

This beta follows the native-backend integration in 6.1.0b1. No Kerykeion
calculation, scoring, chart-rendering or CLI command behavior is changed.
Backend installation guidance and the generated man page follow the new pins.

Libephemeris 4.0.0b2 corrects the public IERS constant's type stub and its
release/test tooling. Its public `python-v4.0.0b1` and `python-v4.0.0b2` tags
have identical `core`, `core/src` and `core/data` Git trees. Calculation bindings
and runtime Python sources are unchanged; the binding-source diff only updates
a package-version assertion inside `cfg(test)`.

## Scientific references

The existing `libephemeris-4.0.0b1` reference model is preserved byte-for-byte.
A separate patch-qualification record binds only the explicitly checked
`4.0.0b2` distribution to that unchanged model. The record includes public source
commits, core/data identities, all five published package SHA-256 values and the
unchanged baseline-manifest digest. Future or otherwise unknown engine versions
still fail model selection instead of falling back automatically.

No original numeric fixture, SVG/report reference, producer attestation,
coefficient file or numerical tolerance is regenerated or widened.

Historical sidereal/house and exact digit-leading fixed-star differences from v3
remain as documented in the [6.1.0b1 migration notes](v6.1.0b1.md#scientific-compatibility).
A patch distribution with the same native model does not restore v3 output.

## Qualification and publication

Package and test results are recorded separately in the
[qualification report](v6.1.0b2-validation.md). The prepared release is not an
upload: registry publication remains a separate maintainer operation.
