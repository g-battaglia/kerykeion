# v6.0.0a60

This alpha bumps the `libephemeris` pin to `3.0.0a6` and regenerates all golden
baselines on the full-range DE441 extended kernel (±8000+).

## DE441 extended-kernel baselines

Positions, SVG charts, report fixtures and configuration goldens now reflect
DE441 across the whole supported range, so ancient and far-future subjects (for
example 500 BCE or 3000 CE) are computed accurately instead of falling back at
the short-range kernel edge. Modern charts are unchanged beyond sub-arcsecond
ephemeris-version drift (libephemeris a4→a6, ≤ ~3.5″ on far-future points only).
Verified against Swiss Ephemeris: at matched ΔT the engines agree to < 0.1″ on
all bodies, and the remaining far-epoch differences are the ΔT-extrapolation
model (documented in libephemeris, benign). The full suite on the extended
kernel reports 10617 passed, 0 failed.

## Fixed

`test_ancient_rome_has_fewer_points_due_to_ephemeris` is now kernel-aware: the
"fewer points due to ephemeris" behaviour only holds on the short-range default
kernel, so with the full-range kernel — where the ancient TNOs are computable —
the test skips with a reason instead of failing.
