# Kerykeion 6.0.1

Release date: 2026-09-14 · Documentation and packaging maintenance · Python 3.12+

This patch improves the documentation for the library and CLI. Both
`kerykeion` and `kerykeion-cli` use version `6.0.1`.

## Changes

The CLI README now introduces **Astrology command line for agents and humans**, with a
prominent link to the dedicated CLI Agent Skill and installation instructions.
It includes an end-to-end chart example, command and parameter discovery,
transit and sky-event recipes, JSON envelopes, exit codes, profile privacy,
ephemeris coverage and links to the full reference.

The main README stays focused on the Python library. Its separate CLI overview
links to the CLI README and skill. The Modern natal chart image now uses an
absolute URL so it displays on PyPI as well as GitHub.

Documentation distinguishes the local CLI from the planned Astrologer API CLI.
Current installation instructions, skill verification versions, the lockfile
and generated man page are updated to `6.0.1`.

## Compatibility and installation

There are **no new breaking changes** from 6.0.0. Calculation, rendering and
public API behavior are unchanged. The default backend remains
`libephemeris==3.2.1` and Python 3.12+ is still required.

```bash
# Python library
pip install --upgrade "kerykeion"

# Library and CLI
pip install --upgrade "kerykeion[cli]"

# Isolated CLI installation (replace an existing uv tool installation)
uv tool install --force "kerykeion-cli"
```

For upgrades from v4 or v5, read the
[migration guide](https://www.kerykeion.net/python-library/docs/v6/migration) and
[6.0.0 release notes](https://github.com/g-battaglia/kerykeion/blob/main/release_notes/v6.0.0.md).

## Maintainer publication checklist

Build both distributions into `dist/6.0.1/`. Keep older artifacts separate.
Verify the prepared files from the repository root:

```bash
shasum -a 256 -c dist/6.0.1.sha256
```

Review the release commit and annotated tag `v6.0.1`, then push them when ready.
Publish the library first:

```bash
uv publish dist/6.0.1/kerykeion-6.0.1-py3-none-any.whl dist/6.0.1/kerykeion-6.0.1.tar.gz
```

Once the library is visible on PyPI, publish the CLI:

```bash
uv publish dist/6.0.1/kerykeion_cli-6.0.1-py3-none-any.whl dist/6.0.1/kerykeion_cli-6.0.1.tar.gz
```

Verify the published packages in a fresh environment:

```bash
uv run --isolated --no-project --with "kerykeion[cli]" kerykeion --version
uv run --isolated --no-project --with "kerykeion[cli]" kerykeion status --check -f json
```

Use these notes for a normal GitHub release, not a pre-release. Preparation does
not publish packages, push the tag or create a GitHub release.
