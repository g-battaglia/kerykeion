# v6.0.0a80 — Modern becomes the default, and its layout becomes measured

This alpha changes what a chart looks like when you do not ask for a style, and
rebuilds the part of the modern wheel that decides where a crowded planet is
drawn. Classic output is untouched apart from its default filenames.

## Breaking: `style="modern"` is the default

`ChartDrawer` defaults to `style="modern"`, so every render call without an
explicit `style=` argument — `generate_svg_string()`, `save_svg()`,
`generate_wheel_only_svg_string()`, `save_wheel_only_svg_file()` — now produces
the concentric-ring layout. Pass `style="classic"` (to the constructor or per
render) to keep the traditional wheel.

Two consequences worth checking before you upgrade:

- **Default filenames now name the style on both sides.** `save_svg()` writes
  `"{name} - {chart type} Chart - Modern.svg"`, and `"... - Classic.svg"` with
  `style="classic"` — the classic file previously had no suffix. Wheel-only
  output follows the same rule (`" - Modern Wheel Only"` /
  `" - Classic Wheel Only"`, previously `" - Wheel Only"`). Aspect-grid-only
  names are unchanged. Code that globs or hardcodes the old names needs
  updating; passing an explicit `filename` bypasses the change entirely.
- **Classic-only options now warn instead of being ignored in silence.**
  `external_view=True`, `show_degree_indicators=False` and
  `show_aspect_icons=False` only take effect with `style="classic"`; rendering
  modern with any of them set logs a warning naming the option, once per drawer.
  The render still succeeds.

## Modern decluttering is measured, displacement-optimal and content-aware

The resolver that spreads crowded planets was rewritten:

- **Measured separations.** The minimum arcs are now derived from real ink,
  measured in a browser under the wheel's pinned font stack, rather than
  guessed: 7.25° natal, 5.75° dual outer, 7.5° dual inner.
- **Least-squares placement.** Placement is an isotonic regression (PAVA) —
  provably the minimum total squared displacement that preserves zodiacal order
  and pairwise separation — instead of a forward walk that anchored the first
  planet of a cluster and pushed everyone else away from their true longitude.
- **Per-pair sizing.** Each adjacent pair reserves the arc its own glyphs,
  degree/minute strings and retrograde row actually need, at the orientation
  where it is drawn.

Worst-case displacement on the reference fixtures: 7.4°→2.7° (stellium),
30.0°→14.3° (all-points natal), 43.4°→13.0° (synastry outer ring); means fell to
roughly a third.

## Modern charts declare their text font

Modern SVGs now carry `font-family="Arial, Helvetica, 'Liberation Sans',
sans-serif"` on the wheel root and, for full charts, on the whole `Main_Chart`
group. No text node declared a font before, so the same chart rendered serif on
its own and inherited whatever font an embedding page used — and no spacing
model can reserve room for an unknown font. **Standalone modern charts therefore
change appearance: their text is now consistently sans-serif.**

Modern SVG baselines, the v6 gallery and the README charts were regenerated
accordingly.
