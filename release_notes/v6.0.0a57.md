# v6.0.0a57

This alpha fixes fixed-star discovery so it no longer drops a bright star to a
position collision.

## The bug

`FixedStarDiscoveryFactory.find_prominent_stars` deduplicated candidate stars by
ecliptic longitude rounded to two decimals (`round(deg, 2)`). With the small
curated catalog this was harmless, but libephemeris 3's 1447-star catalog packs
many physically distinct stars within 0.01° of longitude, so the second star in
catalog order was silently discarded — and catalog order is not magnitude order.
This suppressed astrologically relevant bright stars in favour of faint
neighbours: Nunki (σ Sgr, mag 2.02) was lost to Beta Scuti (mag 4.22), both at
282.26°.

## The fix

Deduplication is now by star identity (`entry.name`) instead of position, so
every distinct star within orb is reported. Discovery results grow accordingly —
more conjunct stars are returned for a given orb.
