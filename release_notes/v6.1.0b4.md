# Kerykeion 6.1.0b4

The library and CLI share version `6.1.0b4`; the CLI pins the matching library
exactly. LibEphemeris remains pinned to the published `4.0.0b4` distribution.
This release remains a beta.

Exact horizon points now consistently select the documented inclusive diurnal
semi-arc. A small production roundoff guard applies only at genuine horizon
boundaries; resolved below-horizon and clamped circumpolar classifications are
preserved. This is an intentional correction to the reported horizon flag and
semi-arc, rather than a change to planetary positions or scientific tolerances.

Coverage metadata is read directly from the native shared calculation snapshot.
The previous Python metadata cache repeatedly statted all inventory paths for
every chart point and retained duplicate records. It is no longer needed by
the pinned native runtime. Its clear hook remains a compatibility no-op.

Optional ephemeris-note text strips invalid XML controls and keeps literal
`var(...)` text intact during CSS inlining. Configured color variables still
work. Default chart output and frozen numerical references remain unchanged.

Development reference generation can validate original-producer temporal inputs
before its destination manifest exists; an existing manifest always takes
precedence. Windows watchdog executables are created suspended and assigned
to their job before the initial thread runs, including venv redirectors.
Glyph regression inputs are read explicitly as UTF-8.

SVG Polish `1.0.1` separately reduces optimizer DOM retention and repeated
attribute traversal while preserving existing golden output. The library
continues to accept the compatible `1.0.x` optimizer API.
