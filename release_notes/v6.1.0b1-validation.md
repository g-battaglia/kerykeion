## Package qualification

`uv build --all-packages --no-sources -o dist` built both wheels and both source
archives. All four pass `twine check --strict`. Versions, Python requirement,
beta classifiers, exact dependency pins, every tracked package source/resource
byte, third-party notices/licenses and the CLI man page were verified.
Tests, local worktrees, validation logs and vendored backend sources are excluded.

All four artifact/interpreter combinations (wheel and sdist pairs on Python 3.12
and 3.14) installed outside the checkout. Source archives rebuilt in isolation;
runtime dependencies resolved from PyPI. Each library-only environment imports
without the CLI, Skyfield/JPLephem/Swiss backend or eager NumPy. It renders a full
natal chart and, with empty HOME and sealed networking, Sun/Moon/Mars and angles
using only bundled data. Installed v2 scoring and canonical model identities pass.
After the matching CLI is installed, version/help/errors/discovery, backend
`status --check`, dependency consistency and the installed/rendered man page pass.

The [artifact manifest](v6.1.0b1-artifacts.sha256) identifies the actual tested
files in `dist/`. `uv publish --dry-run --trusted-publishing never` verified all
four upload files without uploading; authentication belongs to the publisher's
already-configured terminal. See [publication instructions](v6.1.0b1-publication.md).
No PyPI publication was performed.
