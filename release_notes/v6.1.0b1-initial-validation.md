# Initial 6.1.0b1 native-backend qualification

Prepared 2026-11-03 on macOS arm64, using published
`libephemeris==4.0.0b1` from `https://pypi.org/simple` with no Git/local backend
override. Python interpreters: 3.12.13 and 3.14.7. Both distributions are
`6.1.0b1`; the CLI pins the matching library exactly.

All pytest runs below used the complete offline suite (`-m 'not online'`), two
workers, sealed native networking and the stated precision/tier. Skips are not
passes.

Eight warnings per full run remain visible: six existing deprecated-settings

independent solar-altitude oracle. No warning or numerical failure was hidden
by a tolerance change.

## Scientific references

The unchanged 6.0.5/v3 control had two pre-existing failures: a stale man page
and glyph-playground activation. The candidate fixes both. Three house-identity
regressions now force disagreement with the generic numeric house reader rather
than depending on incidental final-ULP cusp ordering.

The remaining 190 original candidate failures were angle/house-model-dependent
reference comparisons, including derived Arabic Parts, report and SVG outputs.
The v4 overlays are separately stored under
`tests/data/model_baselines/libephemeris-4.0.0b1/`: all 41 existing subject/point
inventories are retained; 28 SVGs and one report have explicit variants. The
other 326 SVGs retain their original references. All 398 legacy fixture hashes
and all 12 original LEB2 input hashes remained unchanged.

Independent controls cover 38 non-polar subjects, including the affected ancient
epochs: Skyfield UT1 GAST/date-frame poles, closed-form ASC/MC geometry and a
separate v3 `houses_armc` implementation driven by those independent inputs.
Position errors stayed below **0.000300 degrees** against the existing 0.01-degree
budget. Central-difference rate errors stayed below **0.001641 degrees/day**
against the existing report's 0.01 budget. Polar behavior retains its separate
fallback/identity tests. These are consumer-budget checks, not blanket scientific
accuracy certification or independent SVG certification.

The frozen fixture bytes and scientific/input qualification reproduce exactly
with `scripts/generate_v4_model_baselines.py --check`. The real generating pytest
recipes executed: 569 passed, 12 optional-backend skips. The original producer
attestation remains immutable; the conservative cache hardening changes no
reference byte. Final production-source digest (the generator's `source_digest`
procedure): `e85270df6f40b5182f0f9cd455f46f1a770e9497f408cb6e6223c4e46f97b56b`.
The SVG/report comparator ASTs and tolerance definitions match the original
branch exactly.

## Packages and source checks

- Both wheels and both source archives pass `twine check --strict`; versions,
  exact dependency pins, beta classifiers, bundled licenses/notices, man page
  and shipped source/resource bytes were checked. No private validation output,
  tests or local worktrees ship in the archives.
- All four artifact/interpreter combinations (wheel and sdist pairs on 3.12 and
  3.14) installed outside the checkout. Source archives rebuilt in isolation;
  native dependencies resolved from PyPI. Library-only installs expose no CLI.
- Each installation rendered a full natal chart, then rendered Sun/Moon/Mars and
  angles with an empty HOME, sealed networking and only bundled core data.
  CLI version/help/errors/discovery, `status --check`, matching dependency pin,
  installed man page/rendering and `uv pip check` passed.
- No Skyfield/JPLephem/alternate backend was installed in runtime-only checks.
  NumPy is still required by the immutable published engine's array APIs, but a
  plain Kerykeion import does not load it or the removed Python calculation stack.
- Ruff, MyPy (158 source files), Pyright, import paths/patch targets/loggers,
  fresh-import isolation, locked resolution, CLI smoke/man-page freshness and
  public API documentation coverage (124/124 exports) passed.
- Maintained public Python documentation corpus: 422/422 snippets passed.
  CLI skill: 39/39 runnable blocks passed; three installation blocks remained
  explicitly skipped. Historical worktrees/archives are not this corpus.

The four qualified archives remain local at
`build/v6.1.0b1-verification/dist/`; their hashes accompany these notes in

## Limits

Live GeoNames tests, the optional alternate backend, Cairo/font reconstruction
and Kerykeion consumer execution on Linux/Windows were not qualified here.
LibEphemeris's separate upstream platform checks do not substitute for these
consumer checks. No distribution was published and no release tag was created
by this preparation.
