# Kerykeion 6.0.4

Release date: 2026-09-29 · Documentation and repository maintenance release · Python 3.12+

This patch publishes the revised README wording and repository cleanup on
PyPI. Both `kerykeion` and `kerykeion-cli` use version `6.0.4`; the CLI
continues to pin the library at the exact same version.

## Changes

- Soften the main README's Hosted API section and trim the installation and
  supported-date-range notes.
- Remove the repository-only planning note (`MANDATORY_EVOLUTIONS.md`), the
  release-notes pointer file (`RELEASE_NOTES.md`) and the personal workspace
  starter files (`workspace/`). None of these shipped in the wheels.
- Reword an internal CLI comment that pointed at the removed planning file; no
  runtime behavior change.
- Stop tracking the patch number outside the two `pyproject.toml` files (plus
  the generated man page and the lockfile, which follow them). The agent
  skills, `llms.txt` and the site docs now track the v6 major line, so future
  patch releases no longer touch them.

## Compatibility and installation

There are no calculation, rendering, public API or CLI behavior changes from
6.0.3. The default backend remains `libephemeris==3.2.1`, Python 3.12+ is still
required, and a plain library install still provides no shell command.

```bash
# Python library
pip install --upgrade "kerykeion"

# Library and CLI
pip install --upgrade "kerykeion[cli]"

# Isolated CLI installation
uv tool install --force "kerykeion-cli"
```

For upgrades from v4 or v5, read the
[migration guide](https://www.kerykeion.net/python-library/docs/v6/migration) and
[6.0.0 release notes](https://github.com/g-battaglia/kerykeion/blob/main/release_notes/v6.0.0.md).

## Maintainer publication checklist

The four distribution files are in `dist/6.0.4/`. Verify them from the
repository root:

```bash
shasum -a 256 -c dist/6.0.4.sha256
```

Publish the library first:

```bash
uv publish dist/6.0.4/kerykeion-6.0.4-py3-none-any.whl dist/6.0.4/kerykeion-6.0.4.tar.gz
```

Once the library is visible on PyPI, publish the CLI:

```bash
uv publish dist/6.0.4/kerykeion_cli-6.0.4-py3-none-any.whl dist/6.0.4/kerykeion_cli-6.0.4.tar.gz
```

Verify the published packages in a fresh environment:

```bash
uv run --isolated --no-project --with "kerykeion[cli]" kerykeion --version
uv run --isolated --no-project --with "kerykeion[cli]" kerykeion status --check -f json
```

Use these notes for a normal GitHub release, not a pre-release. Preparation does
not publish packages, push a tag or create a GitHub release.
