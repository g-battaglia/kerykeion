# v6.0.0a49

## Dominants calculator

This alpha adds a **dominants calculator**: the dominant planet, sign, element,
modality and house of a chart, offering several interchangeable calculation
"schools" behind a Strategy pattern, plus a first-class extension point for
user-defined schools.

## What's new

### `DominantsFactory`

```python
from kerykeion import AstrologicalSubjectFactory, DominantsFactory

subject = AstrologicalSubjectFactory.from_birth_data(
    "John Lennon", 1940, 10, 9, 18, 30,
    lat=53.4084, lng=-2.9916, tz_str="Europe/London", online=False)

dominants = DominantsFactory.from_subject(subject, strategy="modern")
dominants.dominant_planet, dominants.dominant_element   # ('Mars', 'Earth')
```

`DominantsFactory.from_subject(subject, strategy=...)` (or the `from_birth_data`
convenience) returns a fixed-shape `DominantsModel`.

### Three built-in schools

Selectable by the new `DominantMethod` literal (`"modern"` / `"almuten_figuris"`
/ `"elemental"`):

- **`modern`** — modern weighted method (Astrotheme-style). Planetary strength
  accumulates from angularity (orb to the four angles), aspect activity
  (weighted by aspect type, orb exactitude and a fast/slow speed tier), a mild
  essential-dignity bonus/penalty, and rulership bonuses. From the planetary
  scores it derives the dominant signs, houses, elements, modes, polarity,
  hemispheres and quadrants. Speed and retrogradation are excluded by design.
- **`almuten_figuris`** — the traditional Lord of the Geniture. Essential
  dignities (domicile 5, exaltation 4, triplicity 3, term 2, face 1) are tallied
  for every classical planet over the five hylegiacal places — Sun, Moon,
  Ascendant, Part of Fortune and the prenatal Syzygy — with an optional
  accidental-dignity layer (house placement, weekday ruler). The technique is
  traditionally tropical; for a sidereal subject the dignities are tallied on the
  sidereal signs.
- **`elemental`** — simple element/modality balance (`weighted` or
  `pure_count`), reusing the library's existing distribution helpers.

### Custom schools (Strategy pattern)

`DominantStrategy` is a `runtime_checkable` Protocol; `BaseDominantStrategy` is an
optional base class that centralizes ranking, percentage normalization and winner
selection. A custom school is any object exposing `name` and
`compute(subject, config)` — no registration step:

```python
from kerykeion import BaseDominantStrategy, DominantsFactory

class MySchool(BaseDominantStrategy):
    name = "my_school"
    def compute(self, subject, config):
        ...  # build and return a DominantsModel

DominantsFactory.from_subject(subject, strategy=MySchool())
```

### Public models

`DominantsModel`, `DominantScoreModel`, `DominantBreakdownItemModel` and the
`DominantMethod` literal are re-exported from the package root and verified
`get_type_hints`-resolvable for runtime (FastAPI) introspection. The model shape
is fixed and school-agnostic: every category is always present (empty when a
school does not compute it), so a single response type serves every school.

## Implementation notes

- Reuses existing building blocks rather than reinventing them: the Ptolemaic
  dignity tables (`kerykeion.dignities`), the element/quality distribution
  helpers, the aspect engine and the rulership data.
- The prenatal Syzygy is found with a self-contained, bracketed bisection over
  the Sun–Moon elongation; all ephemeris access is guarded by `EPHEMERIS_LOCK`,
  and an unresolvable Syzygy (e.g. an out-of-range date) is skipped gracefully
  rather than propagating the error.

## Backward compatibility

Fully additive. No existing behavior, model or signature changes; the new symbols
are added to the package root alongside the existing exports.
