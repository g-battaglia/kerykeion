# Kerykeion 6.1.0b1

Prerelease · Python 3.12+ · library and CLI released together.

## Changes

- Pin the published `libephemeris==4.0.0b1` from PyPI: the Rust engine replaces
  the Python calculation backend. No local checkout or Git override is required.
- Adapt native sessions, coverage/source records, fixed-star lookup and heliacal
  configuration. Retain legacy token cleanup for compatibility.
- Bound metadata-only coverage caching; invalidate it on file/provider changes
  and bypass virtual readers, uninventoried bodies and unserved epochs. No
  astronomical calculations are cached or substituted by this adapter.
- Correct glyph-playground activation and regenerate the CLI man page.
- Keep Skyfield and its reference data development-only. Plain runtime installs
  do not require Skyfield/JPLephem or import that calculation stack. NumPy remains
  a transitive dependency of LibEphemeris's array APIs, but is not loaded by a
  plain Kerykeion import.

## Scientific compatibility

The v4 sidereal/house model changes some historical angles, house cusps and
outputs derived from them. Do not expect ancient charts to reproduce v3 output
bit for bit. Separate, model-labelled references preserve the original 398
fixture files and all existing numerical tolerances. Independent orientation,
house-geometry and rate controls cover 38 non-polar subjects; these checks are
not a blanket accuracy certificate.

The default bundled planetary core remains deliberately small. Additional
bodies and wider date ranges still require the appropriate public LEB2 data.
The optional alternate backend was not qualified for this beta.

## Installation after publication

```bash
pip install --pre "kerykeion==6.1.0b1"
pip install --pre "kerykeion[cli]==6.1.0b1"
```

See the [qualification report](v6.1.0b1-validation.md) for executed checks,
skips and platform limits. Preparing/pushing this branch does not publish either
distribution or create a release tag.
