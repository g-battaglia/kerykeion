# Publish 6.1.0b1

The `release/6.1.0b1` checkout is the beta publication source. The final `dist/`
contains only these four qualified files:

- `kerykeion-6.1.0b1-py3-none-any.whl`
- `kerykeion-6.1.0b1.tar.gz`
- `kerykeion_cli-6.1.0b1-py3-none-any.whl`
- `kerykeion_cli-6.1.0b1.tar.gz`

From that checkout, with the publisher's existing PyPI authentication available:

```sh
uv publish
```

`uv publish` uses `dist/*` by default. Both packages are prereleases; the CLI
pins `kerykeion==6.1.0b1`. Preparation does not upload anything. The
[checksum manifest](v6.1.0b1-artifacts.sha256) identifies the actual tested files;
the [qualification report](v6.1.0b1-validation.md) records the checks performed.

For a later rebuild, use `uv build --all-packages --no-sources -o dist` on this
branch, repeat the package checks and refresh the checksum manifest. Keep any
older or stable distributions outside `dist/` before publishing.

The separate stable 6.1.0 PR changes both package versions, the CLI's exact pin,
classifiers, lockfile and generated man page. Its artifacts must be built and
qualified separately when that release is approved. The prepared beta files
remain `6.1.0b1`.

Reference: [uv package build/publish guide](https://docs.astral.sh/uv/guides/package/).
