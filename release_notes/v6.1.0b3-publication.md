# Manual publication of 6.1.0b3

Build both distributions from the reviewed b3 preparation branch. Verify wheel
metadata, archive contents, isolated library/CLI installs and source-distribution
rebuilds before collecting the four immutable files in a dedicated `dist/`.
The external release manifest records their checksums and exact source commit.

Publish the verified LibEphemeris 4.0.0b4 files first. Then publish the Kerykeion
and CLI 6.1.0b3 files from their dedicated directory with `uv publish`.
No registry upload is performed by preparation.

The development lockfile still records the published b2 dependency set while
b3 is unavailable on the registry. Once LibEphemeris b4 is published, regenerate
it from PyPI with `uv lock --no-sources`, verify that only the intended package
versions/artifact hashes change, run `uv sync --locked --all-extras`, and promote
the b3 metadata plus registry lock to `beta-v6`. Do not commit a local wheel path
as a registry dependency. The lockfile is not included in either source archive.
