# Kerykeion 6.1.0b3

The library and CLI candidate use `6.1.0b3`; the CLI pins the library exactly,
and the library pins `libephemeris==4.0.0b3`. This is a beta, not a stable release.

Native default sessions retain warm readers. Explicit path ownership is tracked
so subsequent default sessions restore discovery without clearing external
settings. Legacy lunar and solar helpers share these rules, including inside
explicit-path sessions; they never forward the empty sentinel to native b2.
Coverage metadata follows native reader-generation changes. Ephemeris
batches support lazy iteration, with the existing list-returning API preserved.

Opt-in SVG ephemeris notes describe omitted and approximate points using the
configured palette in full, wheel-only and grid-only exports. Default output is
unchanged. Nested translation models are copied before validation, and score-v2
inputs reject invalid or inactive required points consistently.

Validation subprocesses preserve caller paths and backend isolation. Reference
recipes are independent of test collection, and patch checks preserve original
producer provenance. Development watchdogs defer stop signals, retain process
group ownership until cleanup, and include Windows Job Object containment.
The Windows watchdog implementation has static review but no local Windows
execution; it is development tooling and is not included in the distributions.

The native model references remain the immutable b1 producer set. The b3
resource patch has a separate source audit and reproduces every reference byte
and scientific/input qualification field. No numerical tolerance or data file
was changed. See [validation](v6.1.0b3-validation.md) and
[manual publication](v6.1.0b3-publication.md).

The [path compatibility report](../docs/native-path-compatibility.md) includes
unmodified b2 negative controls and the b2/b3 regression matrix. Native b3
interprets an empty path as default discovery; `"."` explicitly selects the
current directory. Kerykeion preserves warm defaults instead of repeatedly
applying either sentinel.
