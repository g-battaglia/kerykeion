# Kerykeion 6.0.3

Release date: 2026-09-19 · Documentation maintenance release · Python 3.12+

This patch publishes the revised project documentation on PyPI. Both
`kerykeion` and `kerykeion-cli` use version `6.0.3`; the CLI continues to pin
the library at the exact same version.

## Documentation changes

- Rewrite and reorganize the main README to make installation, API discovery,
  configuration, rendering, licensing and commercial-use guidance easier to
  find.
- Replace the six README theme previews with linked PNG images. The previews now
  render reliably on both GitHub and PyPI and open at full size.
- Update documentation links for the current versioned routes on
  `kerykeion.net`.
- Add a reproducible SVG-to-PNG conversion command and regression tests for the
  README chart preview files and links.

## Compatibility and installation

There are no calculation, rendering, public API or CLI behavior changes from
6.0.2. The default backend remains `libephemeris==3.2.1`, Python 3.12+ is still
required, and a plain library install still provides no shell command.

```bash
# Python library
pip install --upgrade "kerykeion"

# Library and CLI
pip install --upgrade "kerykeion[cli]"

# Isolated CLI installation
uv tool install --force "kerykeion-cli"
```

For upgrades from v4 or v5, read the
[migration guide](https://www.kerykeion.net/python-library/docs/v6/migration) and
[6.0.0 release notes](https://github.com/g-battaglia/kerykeion/blob/main/release_notes/v6.0.0.md).

## Maintainer publication checklist

The four distribution files are in `dist/6.0.3/`. Verify them from the
repository root:

```bash
shasum -a 256 -c dist/6.0.3.sha256
```

Publish the library first:

```bash
uv publish dist/6.0.3/kerykeion-6.0.3-py3-none-any.whl dist/6.0.3/kerykeion-6.0.3.tar.gz
```

Once the library is visible on PyPI, publish the CLI:

```bash
uv publish dist/6.0.3/kerykeion_cli-6.0.3-py3-none-any.whl dist/6.0.3/kerykeion_cli-6.0.3.tar.gz
```

Verify the published packages in a fresh environment:

```bash
uv run --isolated --no-project --with "kerykeion[cli]" kerykeion --version
uv run --isolated --no-project --with "kerykeion[cli]" kerykeion status --check -f json
```

Use these notes for a normal GitHub release, not a pre-release. Preparation does
not publish packages, push a tag or create a GitHub release.
